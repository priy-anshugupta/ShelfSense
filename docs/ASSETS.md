# Asset record

## Generated hero

`frontend/public/images/reading-room.webp` and its original PNG were produced using Codex's **built-in image-generation tool** and copied into this workspace. No API key was needed.

Final prompt:

> Use case: photorealistic-natural. Asset type: ShelfSense library website editorial hero photograph. Wide landscape photograph of an intimate contemporary literary reading room, warm oak floor and bookshelves, arched windows and soft afternoon sunlight, forest-green velvet reading chair, beautiful tactile books and a simple oak desk, cream and deep forest green palette. Eye-level interior photography, believable architecture, serene sophisticated publishing-magazine atmosphere, balanced composition, no people, no readable text, no logos, no watermark, no futuristic elements. This is an original atmospheric illustration of a reading room, not a representation of a real college.

The delivered image was visually inspected. The website labels it as an original editorial illustration.
